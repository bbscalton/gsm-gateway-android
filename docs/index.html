Before you install: rooted phones and normal phones sound different

On a normal phone, Android does not let an app read or feed the audio of a cellular call. So the app turns on the speakerphone. The phone's microphone hears the caller and the loudspeaker plays the extension. It works, but there is echo and room noise. Keep the phone somewhere quiet. The status screen shows Speakerphone (lower quality).

On a rooted phone (Magisk), install the module as well. Android then treats the app as a system app and lets it use call audio directly. On Android 13 and newer, audio is clean in both directions. On older Android, the caller's side is clean, but the extension's side still goes out by speakerphone. The status screen shows the mode in use.

How the bridge works

  1. The app stays registered to the PBX as an ordinary SIP extension. It runs as a foreground service and starts again after a reboot.
  2. A cellular call rings. If SIP is registered, the app answers it after a short delay (1.5 s by default).
  3. The app sends a SIP INVITE to the target extension (default 105). It puts the caller's number in the display name, in P-Asserted-Identity and in X-GSM-Caller.
  4. Audio runs both ways as G.711 (PCMU/PCMA). If the PBX sends keypad presses (RFC 2833), the app plays them as tones to the caller. Keys the caller presses reach the PBX as in-band tones.
  5. When either side hangs up, the other call ends too.

Gateway setup, step by step

  1. Install the APK. Download gsm-gateway.apk on the gateway phone (the one with the SIM), open it, and allow installing from this source if Android asks.
  2. Join Headscale. Install the Tailscale app. Choose Use alternate server, enter https://hs.neuereatec.org, and sign in with the auth key from the office. The key is not published here. Leave Tailscale connected.
  3. Load the settings. Open the setup QR page on another screen and enter the office PIN 418043. In the gateway app, tap Scan QR and scan the extension 150 code, or copy this link and tap Paste link: gsmgw://setup?server=100.64.0.1&port=5060&ext=150&pw=zr2ZSdfLEFtBGTRdH6Qc&target=105. Then tap Save & restart.
  4. What the QR contains: server 100.64.0.1, port 5060, extension 150, password zr2ZSdfLEFtBGTRdH6Qc and target extension 105. Check the fields match.
  5. Permissions. Tap Permissions and allow the microphone, phone, call logs, answering calls and notifications. Tap Battery and choose Unrestricted (battery optimisation off). Default phone app: version 1.0 can't take the default phone app role and doesn't need it, because it answers calls with the “Answer phone calls” permission. Keep your normal dialer as the default.
  6. Check the status. The top panel should read SIP: Registered and Gateway: Idle.
  7. Test. Call the SIM from another mobile. The gateway answers in about 2 s and extension 105 rings with the mobile's number. Answer 105 and talk both ways. Press keys on 105 and listen for the tones on the mobile. Hang up on the mobile and check 105 drops. Call again, hang up on 105, and check the mobile drops.
  8. Rooted phone only: add the Magisk priv-app module for cleaner audio.

Troubleshooting

Level bar stays at 0 during a callThe phone is blocking call audio. Tick Force speakerphone mode, tap Save & restart, and call again.
Not registeredCheck Tailscale: it must be connected to hs.neuereatec.org, and the phone must reach 100.64.0.1. Then check the extension and password (scan the QR again).
Phone rings but is not answeredSIP must be Registered (the app won't answer otherwise), and “Answer phone calls” must be allowed.
Stops working after a while or after a rebootSet Battery to Unrestricted and open the app once after each reboot.

Rooted phone: Magisk priv-app

  1. Install and set up the APK first (above).
  2. In Magisk, open Modules → Install from storage and pick gsm-gateway-magisk.zip. Reboot the phone.
  3. The module copies the app to /system/priv-app/NeuereatecGsmGateway/. It also adds a permission allow-list for CAPTURE_AUDIO_OUTPUT, CALL_AUDIO_INTERCEPTION and MODIFY_PHONE_STATE.
  4. Open the app. The audio mode should start with Rooted:. If it still says Speakerphone, check the result with adb shell dumpsys package org.neuereatec.gsmgateway | grep -E "CAPTURE_AUDIO|INTERCEPTION". Both should show granted=true.
  5. To update later, install the new APK normally. It stays privileged because it is signed with the same key. To undo, remove the module in Magisk and reboot.

Some phone makers lock call audio in their own audio code. On those phones, even root gives silence. If the capture level stays at 0 during a call, tick “Force speakerphone mode”.

PBX side

The gateway needs one normal SIP extension on the PBX (UDP, G.711, dtmf_mode=rfc4733). That extension must be allowed to dial the target. To show the mobile number as the caller ID, set trust_id_inbound=yes on that endpoint. The app sends the number as the display name, so most PBXes show it anyway.

SIPDesk: a desk phone on the same PBX

SIPDesk is our Android desk-phone app. It uses the same QR page.

  1. Download SIPDesk from bbscalton.github.io/sipdesk-android and install it.
  2. Connect it to Headscale (https://hs.neuereatec.org) with the auth key from the office.
  3. Open SIPDesk Settings → Scan QR code and scan that user's extension QR from the setup QR page (office PIN 418043). Then tap Save & Connect.
  4. Test: dial 600 (echo test) and check you hear yourself. Then call 104, the JavisLink softphone, and talk both ways.
